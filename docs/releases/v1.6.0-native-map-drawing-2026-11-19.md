# WhereQ App Hub v1.6.0 — native-map-drawing

> The `/map` drawing tools are back — rebuilt on Google's native maps API,
> with a safety net so a map tool can never take down the site again.

## What's in this release

- **The `/map` drawing tools work again.** Google removed the Drawing
  library from the Maps JavaScript API in v3.65.3b (4 June 2026), and the
  old `DrawingManager` call threw on every API version from 3.65 up.
  Shape drawing had been broken since then, and because the call sat in
  an unguarded effect, a single click on a shape tool replaced the whole
  app with an error page.
- **Drawing now runs on native maps overlays.** The map feature only
  ever used the deprecated library as a click-to-draw layer — everything
  else was already native — so the migration replaced just the input
  layer. Polygon, polyline, circle, rectangle and marker all behave as
  before, including vertex editing, click-to-highlight and custom
  marker icons.
- **How it works now:** click to place vertices, double click to finish
  a line or polygon; a circle takes a centre click then an edge click; a
  rectangle takes two corners; a marker takes one click. A rubber band
  follows the pointer while you draw.
- **Drawing failures can no longer break the site.** Every drawing step
  is guarded. If something goes wrong, the shape buttons grey out and a
  short notice appears — the rest of the app carries on.
- **Documentation corrections.** The architecture notes and the release
  notes now describe the Drawing library removal accurately, including
  the verified API-version matrix and why this app draws natively rather
  than adopting Terra Draw or pinning an old API version.

## Notes

- The release notes live in
  `docs/releases/v1.6.0-native-map-drawing-2026-11-19.md`.
- The git tag for this release is `v1.6.0`.
- Status is `shipped`, set by `--status`.
- The deprecated `google.maps.drawing` surface, the `drawing` library
  request and the local type augmentation are all gone from the repo.
- No new dependencies, and no API version pin to retire later.
- Drawing was verified in the browser against a stubbed maps API, since
  the feature needs a user-supplied Google Maps key that the lab does
  not ship.
