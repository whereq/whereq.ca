# WhereQ App Hub v1.13.1 — flag-blurb

> The CountryFlag description now counts the countries instead of calling the registry small.

## What's in this release

- **The CountryFlag blurb matches the page.** The documentation column read
  "Country flags drawn as inline SVG from a **small** built-in registry",
  while the demo right next to it said "a built-in registry of 65
  countries". It now says the same thing: 65.
