# WhereQ App Hub v1.8.7 — camera-and-panel

> Two real defects in the map: a search that resolved but never moved the
> map, and a settings panel that did not sit where it belonged.

## What's in this release

- **A search now moves the map.** The search resolved correctly all along —
  the address was geocoded, the input filled in, the recent-search list was
  written — but the map never budged and no marker appeared. The cause was
  `<Map center={...} zoom={12}>`: those are *controlled* props, and the
  library re-applies them on every render, snapping the camera back to the
  start position the instant anything moved it. The map now uses
  `defaultCenter` / `defaultZoom`, which set the initial view without pinning
  the camera. Picking a place pans to it, zooms to 15 and drops the marker.
- **The settings panel now covers the map area exactly.** It used to start
  16px inside the left icon bar, stop short of the right edge, and run under
  the footer. It now sits flush after the left bar, below the header and
  above the footer, and covers the map surface completely.
- **The map's search box and tool bar no longer fight the panel.** They were
  moved out of the `<Map>` subtree so their suggestion list can paint over
  the map surface, and the settings panel sits above them.

## Notes

- **How the camera bug was found.** The headless browser showed the marker
  and the map moving, so the automated checks passed. The real GPU browser
  told the truth: the search filled the box, wrote the recent search, and
  left the map exactly where it started. The library's own source explains
  it — `use-map-camera-params.ts` runs on every render and calls
  `map.moveCamera()` whenever the live camera differs from the props.
- **How this was checked:** in real Chrome on the vector map, a search for
  "banff" now pans the map to Banff and places the marker, and the settings
  panel measures exactly `left 64px` (the left bar's width), `top 50px` (the
  header's height), `right 0` and `bottom` at the footer's top edge — no
  overlap with the header, the left bar or the footer.
