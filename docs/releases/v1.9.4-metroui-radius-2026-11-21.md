# WhereQ App Hub v1.9.4 — metroui-radius

> The Lab and the app chrome now wear the WhereQ universe's MetroUI look, and every corner in the application sits on the same 2px radius.

## What's in this release

- **One palette, the MetroUI one.** The Lab hub, the `@whereq/react` demo and the app chrome now use the WhereQ universe's palette — orange `#f5a623` accent, cream `#f0e6c8` text, orange-tinted hairlines on the deep slate `#161b27` — the same one the rest of the WhereQ family uses. The Lab hub and the demo had been carrying the deep-space blue of the marketing page; that page is the one surface that keeps its own theme, because it renders full-bleed outside the shell.
- **One radius: 2px, everywhere.** The app's corner radius is now the xs step across the board — cards, panels, dialogs, buttons, form fields, chips, the Lab tiles, the search box. Both the MetroUI radius ladder and Tailwind's own radius scale collapse to 2px, and Tailwind's *bare* radius utilities (which are hardcoded at 4px and are not theme-driven) are overridden explicitly. Circles stay circles: `rounded-full` is untouched.
- **No more horizontal scrollbar in the demo's left panel.** The live-demo panel had a scrollbar along the bottom because the resize handle straddles its right edge. The panel now clips that overflow, and the code samples wrap instead of running off the side.
- **A wider demo panel.** The workspace starts at 440px instead of 380px, so a code sample fits without being broken mid-expression.
- **A squashed install block, fixed.** The `yarn add @whereq/react` line lost 8px of height and grew a scrollbar of its own — Tailwind v4's preflight turns `<main>` into a flex container, so the blocks inside it are flex items and can shrink below their content. The panels now hold their size.

## Notes

- The library's own theme variables (`--rule`, `--text`, `--accent`, …) are now supplied in the MetroUI flavour, so the shared `Tag` and `Toast` components sit natively inside the app instead of borrowing the marketing page's blue.
- The map's search box follows the same radius rule (2px) as every other field.
- Verified in a real browser against the production build: every surface measures a 2px corner radius, the demo's left panel has no horizontal scrollbar, the install block keeps its height, the toast paints with its tint and the shared chips render in the app's colours. No console errors on `/lab`, `/react`, `/map`, `/tools`, `/api-explorer` or `/about`.
