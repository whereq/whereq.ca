# WhereQ App Hub v1.12.0 — flag-row

> The flag row in the WhereQ React demo is now a row of country codes, with Russia in place of Japan.

## What's in this release

- **The flags are labelled with the country code alone.** The row read
  `CA - CANADA`, `CN - CHINA`, `USA - UNITED STATES` — the code and the
  name, every time. It now reads `CA`, `CN`, `USA`, `UK`, `RU`, `FR`, `DE`,
  `EU`: the code is the thing you look up, and a row of codes reads as a
  row of codes.

- **The full name is still one hover away.** Each flag carries its
  country name as a tooltip, so nothing is lost by the shorter label.

- **Russia replaces Japan.** The row showed eight flags; Japan is out and
  Russia takes its place.

## Notes

- The release notes live in `docs/releases/v1.12.0-flag-row-2026-11-22.md`.
- The git tag for this release is `v1.12.0`.
- Status is `shipped`, set by `--status`.
- The labels are the demo's own codes (`us` → `USA`, `gb` → `UK`), not
  the library's slugs. The library's slugs are ISO 3166-1 alpha-2 codes,
  with `uk` kept as an alias for `gb`.
