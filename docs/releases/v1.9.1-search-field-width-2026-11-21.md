# WhereQ App Hub v1.9.1 — search-field-width

> The /map search field now spans the full width of the tool panel, aligned edge-to-edge with the toolbar below it.

## What's in this release

- **The search field fills the panel.** The address field in the `/map` tool panel now stretches to the full inner width of the panel, so its right edge lines up exactly with the tool buttons underneath. Previously it was fixed at `w-72` and stopped short, leaving an awkward blank gap on the right.
- **The suggestion list follows the field.** Because the dropdown is anchored to the field, it now opens at the panel's full width too — no more list that is wider or narrower than the box above it.
- **No behaviour change.** Typing, the suggestion list, the clear (×) button, the magnifier submit, and both submit paths (picking a suggestion → place details; free text → geocoding) are untouched.

## Notes

- The fix is layout-only: `MapSearchBox` now defaults to `w-full`, and the tool panel row uses `items-stretch` so the field and the toolbar share the same width.
- Verified in a real browser against the production build: field and toolbar both report the same left and right edges, with a gap of 0 on the right, and 0 console errors.
