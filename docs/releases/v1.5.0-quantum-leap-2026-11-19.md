# WhereQ App Hub v1.5.0 — quantum-leap

> A dependency leap, a new planet in the galaxy, and a rewritten About page.

## What's in this release

- **All dependencies updated to the latest stable releases.** React
  19.3.1, Vite 8.3.8, TypeScript 6.0.3, Tailwind CSS 4.3.5, ESLint
  10.15.0, `@imgly/background-removal` 1.7.0, `react-ace` 15,
  `react-day-picker` 10.0.2, `js-yaml` 5.5.0, `pyodide` 314.0.8 and
  more. Prerelease pins were replaced with stable ones — notably
  `onnxruntime-web` is now the stable `1.21.0`.
- **WhereQ-DOSBox joins the Universe** as a standalone showcase planet
  with no dependency edges — a native Android port of DOSBox with an
  on-screen keyboard, a touch mouse, and save states. It has its own
  deep dive, a CRT scanline motif, and a footer link.
- **The About page now covers the whole Universe.** The WhereQ Inc.
  section lists all 13 WhereQ Universe projects and applications, and
  the Scotiabank section picks up two AI achievements: the Data GPT /
  90-90 KPI platform work and the evaluation and integration of
  emerging AI technologies into reusable enterprise frameworks.
- **The Projects grid on `/about` now lists all 13 projects.** WhereQ
  — LLM points at the public
  [whereq-llm-api](https://github.com/whereq/whereq-llm-api) repository
  and is no longer marked "coming soon". WhereQ Lab and WhereQ — LLM
  both use the whereq.ca favicon as their logo.
- **All About-page logos are now local assets.** The previous remote
  logos were blocked in production by the COOP/COEP header, so they
  never loaded.

## Notes

- The release notes live in
  `docs/releases/v1.5.0-quantum-leap-2026-11-19.md`.
- The git tag for this release is `v1.5.0`.
- Status is `shipped`, set by `--status`.
- TypeScript is held at `~6.0.3` rather than 7.x: `typescript-eslint`
  8.73.0 declares a peer range of `>=4.8.4 <6.1.0`, and the release
  gate runs `yarn lint`.
- The Google Maps Drawing library was removed upstream in Maps JS API
  v3.65.3b (4 June 2026). Its types are supplied by a local augmentation
  in `src/types/google-maps-drawing.d.ts`, so `tsc` stays clean — but
  that augmentation is types-only, and the runtime constructor throws on
  every API version ≥ 3.65. The `/map` feature loads the default channel
  because its `<APIProvider>` sets no `version` prop, so shape-drawing
  tools are already broken in production, and the unguarded throw
  reaches the root `ErrorBoundary`. This predates this release and is
  fixed in the next one, by drawing on native `google.maps` overlays.
