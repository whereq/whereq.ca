# WhereQ App Hub v1.11.0 — flag-codes

> The United Kingdom flag shows up again in the WhereQ React demo, and every flag carries its short code.

## What's in this release

- **The UK flag is back.** In the `@whereq/react` demo, the United
  Kingdom's flag came back as an empty box. The demo asks for the country
  code `gb`, and the library's flag registry keyed the United Kingdom
  under `uk` — so the lookup missed, and an unknown country drew nothing
  at all. The library now keys the United Kingdom under `gb` (the code
  everyone else uses) and keeps `uk` as an alias, so both spellings render
  the Union Jack.

- **An unknown country is never an empty box.** The library has always
  promised a neutral fallback emblem for a country it has no flag for;
  that fallback was never wired up. It is now: a flag chip always shows
  something.

- **Every flag carries its short code.** The demo labels each flag with
  the code and the name it stands for — `CA - CANADA`, `CN - CHINA`,
  `USA - UNITED STATES`, `UK - UNITED KINGDOM`, `JP - JAPAN`,
  `FR - FRANCE`, `DE - GERMANY`, `EU - EUROPE`. The code is the thing you
  look up; the name is the thing you read.

## Notes

- The release notes live in `docs/releases/v1.11.0-flag-codes-2026-11-22.md`.
- The git tag for this release is `v1.11.0`.
- Status is `shipped`, set by `--status`.
- The flag fix is in the library, not in the app: `@whereq/react`
  **0.9.5**. The demo renders the published package, so it could not show
  the fix before the library was released.
- The library's slugs are ISO 3166-1 alpha-2 codes (`us`, `cn`, `gb`),
  with the continent pseudo-codes `na` and `eu`. `uk` is kept as an
  alias for the United Kingdom.
