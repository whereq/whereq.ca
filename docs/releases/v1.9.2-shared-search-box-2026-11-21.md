# WhereQ App Hub v1.9.2 — shared-search-box

> The /map search box is now the shared @whereq/react component, so it is written once for the whole whereq universe instead of once per app.

## What's in this release

- **One search box, written once.** The `/map` search box renders from `@whereq/react` (v0.8.0) — the new, generic `SearchBox` component — instead of the app's own copy of the markup. The control is now maintained in the open-source library, so every whereq app can use the same one rather than keeping a private duplicate.
- **No change for the user.** The field, the magnifier, the clear (×) button, the suggestion dropdown, the keyboard navigation (↑ / ↓, Enter, Escape) and the full-width layout are exactly as before — the app passes the MetroUI colours to the component as a theme, so the panel looks identical.
- **A leaner map feature.** The map's own search hook now only fetches, resolves and reports; the highlight, the list and the ARIA wiring live in the library.

## Notes

- The library component is new: `@whereq/react` 0.8.0 adds a generic, themeable `SearchBox` (field, magnifier-as-submit, clear button, dropdown, keyboard navigation, `combobox` / `listbox` / `option` ARIA wiring, click-outside handling), themed through the `--wq-search-*` CSS custom properties. It ships with 21 unit tests.
- Verified in a real browser against the production build: the field still spans the full panel width (right edge aligned with the tool bar, gap 0), the dropdown opens with suggestions, picking a suggestion fills the box and moves the map, and the magnifier still submits free text.
- The release notes live in `docs/releases/v1.9.2-shared-search-box-2026-11-21.md`.
- The git tag for this release is `v1.9.2`.
- Status is `shipped`, set by `--status`.
