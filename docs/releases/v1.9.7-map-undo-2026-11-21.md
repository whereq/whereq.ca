# WhereQ App Hub v1.9.7 — map-undo

> A shape you deleted on the map can now be put back — by button or with Ctrl+Z.

## What's in this release

- **An Undo button on the map tool bar.** It sits next to Delete and is
  greyed out until there is something to undo. Its tooltip says what it
  does.

- **Ctrl+Z does the same thing** (Cmd+Z on a Mac). The shortcut is left
  alone inside a text field, where it belongs to the text you are typing.

- **A shape comes back exactly as it was.** A deleted shape is not redrawn
  from scratch — the very same shape goes back on the map, with the
  vertices you dragged on it and the name you gave it.

- **It comes back in the right place.** The shape goes back where it used
  to sit in the drawing, so the order of your shapes does not change and
  the exported GeoJSON file keeps the features in the order you drew them.

- **You can see what came back.** The restored shapes come back selected,
  so the undo brings them to your eye instead of quietly re-drawing them.

- **Several shapes at once work too.** Select a few, delete them, and undo
  puts all of them back, in their original places.

- **Undo says when there is nothing to undo** instead of doing nothing
  quietly.

## Notes

- The release notes live in `docs/releases/v1.9.7-map-undo-2026-11-21.md`.
- The git tag for this release is `v1.9.7`.
- Status is `shipped`, set by `--status`.
- Undo covers **deletions only** for now. Grouping, ungrouping and saving
  are not undoable yet.
- The app remembers the last 20 deletions. Loading a saved map, or
  leaving the map page, clears them — the shapes belong to the drawing
  they were drawn in.
- Deleting a shape never touches the saved copies in "My Map"; those are a
  separate collection, as before.
