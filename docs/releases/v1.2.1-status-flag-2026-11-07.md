# WhereQ App Hub v1.2.1 — status-flag

> **A small follow-up: the release script can now write the release note's own status line.**

## What's in this release

- **`--status <shipped|draft|yanked>`** on `bin/release.sh`. The scaffolded
  release note previously hard-coded `status: draft`, which meant every
  release needed a second commit to correct the front-matter once the
  Vercel deploy went live. The flag sets the status up front.
- **The v1.2.0 release note is now a real release note** — it was scaffolded
  by the script and left as a template with `status: draft`. It now carries
  the actual v1.2.0 content and `status: shipped`, matching the live
  deploy.
