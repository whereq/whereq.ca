# WhereQ App Hub v1.8.1 — clean-up

> One map implementation instead of two, and the leftovers it was
> keeping alive are gone.

## What's in this release

- **The old second copy of the map is gone.** The lab carried a second,
  older Google Maps implementation (`map-gl/`) that was never wired to a
  route. It had been kept "for reference", but it still carried its own
  copy of the search box, its own drawing toolbar and its own settings
  panel — so every change to the map had to be made twice, or the copy
  quietly drifted. It is deleted, and the live map feature is now the
  only one.
- **The dead drawing toolbar is gone.** The old toolbar component was
  already marked as deprecated in its own documentation and had not been
  rendered for a long time.
- **Two unused dialogs are gone.** The map feature had a "delete menu"
  and an "info window" dialog that nothing imported.
- **Six unused helpers are gone.** The old search code had left behind
  six functions that built map objects from Google's retired result
  format — they had no callers left once the new search box landed.
- **The documentation now matches the code.** The architecture notes
  described the deleted copy, the old toolbar and the duplicated
  settings panel as if they were still there; those entries are gone,
  and the feature count in the table of contents is corrected.

## Notes

- **Nothing user-visible changed.** The map, the search box, the drawing
  tools and every other lab feature behave exactly as they did in
  v1.8.0 — this release only removes code that was unreachable.
- **The release notes live in
  `docs/releases/v1.8.1-clean-up-2026-11-19.md`.**
