# WhereQ App Hub v1.13.0 — more-flags

> The flag row in the WhereQ React demo grows from eight countries to twenty-four, and the library behind it now draws sixty-five.

## What's in this release

- **The flag row shows twenty-four countries.** It read `CA, CN, USA, UK, RU,
  FR, DE, EU`; it now reads `CA, CN, USA, UK, FR, DE, IT, ES, MX, BR, JP, KR,
  IN, PK, SG, RU, TR, EG, ZA, AU, NL, SE, PL, EU`. Japan is back, and so are
  South Korea, India, Pakistan, Singapore, Mexico, Spain and Italy.

- **The library's registry grew to sixty-five countries.** The demo shows
  twenty-four of them; the package knows the rest. Pakistan, Singapore,
  Algeria, Morocco, Kuwait, Qatar, Kenya, Kazakhstan, Croatia, Czechia,
  Chile, Uruguay, Bangladesh, Sri Lanka, Ukraine, Colombia, Ecuador, Peru,
  Nigeria and Bulgaria are all new.

- **India and South Korea get their emblems.** India was a bare tricolor and
  now carries the Ashoka chakra; South Korea was a plain two-tone disc and
  now carries the taegeuk with its four trigrams.

- **Saudi Arabia stops drawing the letters "SA" on green.** It gets the
  script and the sword, as far as they survive at chip size.

- **`@whereq/react` moves to 0.10.0.** The demo renders the published
  package, so the new flags are the real ones, not a mock-up.

## Notes

- The release notes live in `docs/releases/v1.13.0-more-flags-2026-11-22.md`.
- The git tag for this release is `v1.13.0`.
- Status is `shipped`, set by `--status`.
- Every new flag was drawn in the library against a **reference image**,
  not from memory — a flag drawn from memory is a flag that is subtly
  wrong. The crescent of Pakistan opens up and to the right, Qatar's white
  band is at the *hoist*, and Kuwait's black trapezoid has its base on the
  hoist edge. Each render was compared side by side with the reference
  before it was committed.
- The library keeps one row per country: `in2` and `nl2`, which were
  duplicates of India and the Netherlands, are aliases now.
