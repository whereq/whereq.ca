# WhereQ App Hub v1.10.0 — group-shapes

> A shape inside a group can now be picked and deleted on its own, and the WhereQ React demo finally has room for its code.

## What's in this release

- **A grouped shape can be picked on the map.** Before, only a shape that
  sat at the top of the drawing could be picked — a shape you had put into
  a group was drawn on the map and clickable, but clicking it did nothing.
  Now it is selected and highlighted like any other shape.

- **A grouped shape can be deleted on its own.** The delete takes the
  shape out of its group and off the map. The group stays, with what is
  left of it, so the rest of your grouping is untouched.

- **Undo puts a deleted grouped shape back where it was** — back into its
  group, in the place it held, not loose at the top of the drawing.

- **A shape can be moved into a group of its own.** A shape that is
  already in one group can now be picked together with a shape from
  another group, and the two can be grouped together.

- **Grouping no longer shuffles your drawing.** The group used to be put
  at the end of the drawing, which changed the order of the exported
  GeoJSON file. The group now takes the place of the first shape it
  holds, so grouping a run of shapes leaves the drawing — and the file —
  in the order you drew them.

- **The WhereQ React demo gives the code the room.** The demo side of the
  page starts at 58% of the width instead of a fixed 440 pixels, so the
  live component and its example code have real space.

- **The example code never wraps.** A long line of code used to break
  into two, which makes a snippet hard to read — you have to work out
  which part belongs to which line. The samples now keep every line on
  its own line, and a line that is too long scrolls sideways instead.
  The longest sample fits without scrolling at all.

- **The documentation side of the React page is a readable column.** It
  was a full-width band of cards; it is now a column, and the component
  cards are a vertical list inside the library's own scrollbar — the very
  primitive the page is demonstrating. A longer list scrolls instead of
  pushing the page down.

## Notes

- The release notes live in `docs/releases/v1.10.0-group-shapes-2026-11-22.md`.
- The git tag for this release is `v1.10.0`.
- Status is `shipped`, set by `--status`.
- The map's drawing is a tree: a shape inside a group is held by the
  group rather than by the drawing itself. The new tree helpers are what
  make a grouped shape findable, so anything that looks a shape up by id
  has to walk the tree rather than the top level list.
- The demo side of the React page can still be dragged wider by its
  handle, up to 74% of the page.
